# 新手阅读指南：怎么啃这个项目

> 配套 [技术报告-新手版](技术报告-新手版.md) 先读。这篇回答：先看什么、后看什么、怎么验证"我读懂了"、卡住了怎么办。
> 本项目每个 js 文件头部都有一段【新手阅读提示】注释，读任何文件前先看它的头注释。

## 0. 心法：读代码 ≠ 从第一行读到最后一行

读陌生项目的正确姿势是**带着一条具体的线索追**（比如"点击地面后发生了什么"），沿着调用链跳着读，追完一条线索再换下一条。通读是最后一步，不是第一步。下面 §3 给你准备好了三条线索。

## 1. 准备工作（半小时）

1. **把游戏玩一遍**（15 分钟）。双击 `实验史记·马刀行.html` 或 `index.html`：开卷选难度→跟「令」打第一节主线→打赢看录技。你要先知道"好的时候它长什么样"，读代码时才有画面感。
2. **装 VSCode**（或任何能高亮 JS 的编辑器），打开整个 `shiji-madao-notes` 文件夹（文件→打开文件夹），别单开文件——你需要全局搜索。
3. **学会三个浏览器快捷键**（按 F12 打开开发者工具）：
   - `Ctrl+Shift+F`（在 DevTools 的"来源/Source"面板里）：在**加载的全部脚本**里搜关键词；
   - `Ctrl+P`（Source 面板）：按文件名快速打开某个 js；
   - `console` 标签：任何报错都会在这里，红字第一行通常就是罪魁文件和行号。

## 2. 读代码前要会 JS 的哪些东西（最小清单）

这个项目用到的语法全部是日常款，遇到不会的现场查也来得及。按出现频率排：

| 概念 | 一句话解释 | 在项目里的样子 |
|---|---|---|
| 对象与数组 | `const x = {a:1}` / `const a = [1,2]` | 数据表文件全是这个 |
| 函数 / 箭头函数 | `f = (x) => x + 1` 等价 `function f(x){return x+1}` | 到处都是 |
| `const`/`let` | const 不可重新赋值（内容可变）；let 可 | 全项目几乎不用 var |
| 模板串 | `` `第${n}日` `` 反引号里 `${}` 填变量 | 文案拼接 |
| 解构 | `const {hp, atk} = unit` 一次取多个字段 | 战斗代码常见 |
| IIFE | `const X = (() => { ... return api; })()` 定义即执行，内部变量外界看不见，只暴露 return 的接口 | **每个大模块都是这个形状**（World/Main/Quests…），看见就知道这是"一个模块" |
| 闭包 | 内层函数记住外层变量 | IIFE 能封模块就靠它 |
| DOM | `document.querySelector('#hud')` 拿页面元素，`.textContent` 改字，`.addEventListener('click', fn)` 挂点击 | 界面代码 |
| 事件监听 | 同上，`keydown`/`pointerdown` 同理 | world.js 输入 |
| Canvas | `ctx.fillRect(x,y,w,h)` 在画布上画矩形，每帧重画 | world.js 校园 |
| requestAnimationFrame | `function loop(){...; requestAnimationFrame(loop)}` 每秒约 60 次循环 = 游戏主循环 | world.js |
| localStorage | `localStorage.setItem('key', 字符串)` 浏览器永久存小数据 | config.js Save |
| 三元/短路 | `cond ? a : b`；`x && f()`（x 为假就不执行） | 到处都是 |
| 展开与可选链 | `[...arr, n]` 复制再加；`obj?.a`（obj 为空不报错） | 战斗代码 |

不用先学完再读——开一张"生词本"，遇到不认识的语法记下来，当天查掉。

## 3. 三条追踪线索（核心练习，建议照做）

### 线索 A：「点一下地面，小人为什么会走？」（世界层热身）

1. 打开 `js/world.js`，全局搜 `pointerdown`（或 `addEventListener`）——这是输入入口；
2. 从点击坐标到网格坐标的换算（注意相机偏移）；
3. 搜 `BFS` 或 `path`——寻路：从起点到终点逐层扩散找最短路；
4. 搜 `requestAnimationFrame`——主循环：每帧沿路径挪一小步并重画全场景。
**通关标志**：你能说出"从鼠标点击到小人挪一格，数据经过了哪几步"。

### 线索 B：「走近『令』，战斗是怎么打起来的？」（跨层主线，最重要）

照技术报告 §5 那条链，逐站跳：
`main.js` 搜 `onQuest` → `quests.js` 搜 `start(` 看 cfg 怎么组（注意 `cfg.stage`）→ `battle-ui.js` 搜 `startBattle` → `battle/engine.js` 搜 `init` 或回合主函数 → 打完 `main.js` 搜 `SJI_BATTLE_HOOKS` 看 `onResult`/`onDone`。
**通关标志**：你能在纸上画出这条链的箭头图。

### 线索 C：「打赢之后，他的招怎么到我刀谱里的？」（数据流动）

`battle-ui.js` 结算区 → `main.js` onResult → `blades.js` 搜 `learn` 或录技相关（`_learnedFrom` 标记）→ `ui.js` 刀谱面板怎么读刀谱数据。
**通关标志**：你能解释"刀谱数据存在哪个对象里，谁写它、谁读它"。

## 4. 推荐阅读顺序（三阶段）

**第一阶段·工具与外围（短平快，建立信心）**
`index.html`（DOM 骨架，认 id）→ `js/config.js`（158 行工具箱，每个函数都短）→ `js/data/items.js`（36 行，看看"数据表"长什么样）→ `js/dialog.js`（对话播放器，顺带理解"回调兜底"设计）。

**第二阶段·世界层**
`js/engine.js`（193 行状态机）→ `js/data/` 其余表（结合头注释的字段字典）→ `js/world.js`（主循环/寻路/输入，配合线索 A）→ `js/ui.js`、`js/writing.js`、`js/minigames.js`（可后置）。

**第三阶段·战斗链（硬骨头，按此序）**
`js/quests.js`（任务数据结构，先看 DIFFS 和 MAIN 的表头注释）→ `js/blades.js` → `js/battle/config.js` → `js/battle/data.js`（先懂"角色卡"字段）→ `js/battle/engine.js`（1465 行，**按它头注释给的顺序读**：配置→初始化→回合循环→技能/特则，别横着硬推）→ `js/battle-ui.js` → `js/main.js`（总指挥最后读，此时所有名字你都见过）。

**别碰区**：`js/battle/ui.js` 和 `js/battle/main.js` 是原版遗留参考件，index.html 根本不加载，读到怀疑人生请立即退出——正式战斗界面在 `js/battle-ui.js`。

## 5. 调试工具箱

- **看存档**：DevTools → Application（应用）→ Local Storage → `shiji_cqb_v1`（世界档）/`shiji_madao_v1`（战斗档）。改坏游戏可焚稿重开。
- **console 里直接玩**：页面开着时，console 是连着游戏全局的。试试 `Quests.chapterNow()`、`G.ch`、`Blades`——全局变量都能直接敲。
- **隐藏调试钩子**：战斗层有 `SJI_DEBUG`（见 `js/battle/main.js`，虽是遗留文件但钩子设计一致）：`SJI_DEBUG.fast=true` 快进动画、`SJI_DEBUG.killEnemies()` 秒杀、`SJI_DEBUG.giveAll()` 刀马全给。读战斗代码时用它跳过摩擦。
- **下断点**：Source 面板打开目标 js，点行号下断点，触发后用 `F10` 逐行、看右侧变量。比 console.log 快。
- **跑测试当"读后感验证"**：改了战斗引擎？`node tests/battle/engine/test_rules2.mjs` 立刻告诉你有没有改坏。

## 6. 动手练习（由易到难，全部数据驱动，改数据表即可）

1. 【台词】把某个对手的某句挑衅换成自己的话（`js/quests.js` 的 `foe` 池）。刷新页面验证。
2. 【数值】把 m1 难度的敌人血量砍半（`quests.js` 或 `battle/data.js`），打一遍感受差异。
3. 【道具】在 `js/data/items.js` 加一个新道具并给某个事件当奖励。
4. 【支线】照 `SIDE` 表里现成的一条，复制改出一个新支线（`quests.js`）。
5. 【特则】给 `battle/engine.js` 加一种新特则（照现有 9 种之一的模式），并去 `tests/battle/engine/test_rules2.mjs` 补一个断言——体会"测试先行"。

## 7. 卡住了怎么办

- 看不懂一段代码 → 先看它所在文件的**头注释**和最近一个**区块注释**，确认自己知道"这在哪个部位"；
- 报错红字 → 复制第一行去搜，八成是 `undefined`（对照坑清单第 1 条：是不是写成 `window.X` 了）；
- 改了没生效 → 是不是改的是**遗留文件**（battle/ui.js）？或者忘了打包（单文件版要重新 `python build.py`）；
- 还不行 → 问 AI 的时候把"文件名+这段代码+你想干什么"一起给，答案质量翻倍。
