# 实验史记 · 马刀行

> 开放校园，四处游历；来呀来呀，以刀会友。
> 据 音克思《实验史记》改编 · 卷里卷外，皆是少年；刀起刀落，皆是青春。

《实验史记·马刀行》是一款**零依赖、双击即玩**的网页游戏：以《实验史记·春秋笔》的高密度箱庭校园为"开放世界"外壳，以《实验史记·马刀风云》的 7×7 马刀战棋为全部战斗内核。你扮演史官**音克思**，在高二到高考的三年里自由探索校园——走近会马刀的人，说一句"来呀来呀"，便是一场对决；胜一场，录一技，为立传而战。

## 快速开始

- **直接玩**：双击 `实验史记·马刀行.html`（单文件版，零外部资源，file:// 可玩）。
- **开发模式**：双击 `index.html`，或 `python -m http.server` 后访问。
- **打包**：`python build.py` → 生成单文件 `实验史记·马刀行.html`。
- **测试**：
  - 引擎层：`node tests/battle/engine/test_duel.mjs` 等 13 个 Node 测试（无需浏览器）；
  - 全链路：`node smoke.mjs`（Playwright，34 项断言 + 验收截图入 `testshots/`）。

## 设计约定

- **零依赖**：原生 JS + Canvas 2D + WebAudio 程序合成，无任何外部资源与网络请求。
- **数据驱动**：机制与内容分离；加人物改 `data/people.js` + `battle/data.js`，加支线改 `data/events.js`，加卷改 `data/volumes.js`。
- **引擎不动世界**：战斗引擎通过 `window.SJI_UI` 钩子与覆盖层通信，通过 `SJI_BATTLE_HOOKS` 与世界结算，两侧可独立测试。

## 存档

世界进度存于 `localStorage['shiji_cqb_v1']`（自动 + base64 导出/导入）；战斗侧偏好与断点存于 `shiji_madao_v1`。设置面板可导出/导入/焚稿重开。
