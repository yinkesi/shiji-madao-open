# 实验史记 · 马刀行

> 开放校园，四处游历；来呀来呀，以刀会友。
> 据 音克思《实验史记》改编 · 卷里卷外，皆是少年；刀起刀落，皆是青春。

《实验史记·马刀行》是一款**零依赖、双击即玩**的网页游戏：以《实验史记·春秋笔》的校园箱庭为"开放世界"外壳，以《实验史记·马刀风云》的 7×7 马刀战棋为全部战斗内核。你扮演史官**音克思**，在一个自由来去的校园里接主线、办支线——走近「令」标记，便是一节高难关卡；胜一场，录一技，为这部刀史收卷。

## 快速开始

- **直接玩**：双击 `实验史记·马刀行.html`（单文件版，零外部资源，file:// 可玩）。
- **开发模式**：双击 `index.html`，或 `python -m http.server` 后访问。
- **打包**：`python build.py` → 生成单文件 `实验史记·马刀行.html`。
- **测试**：
  - 引擎层：`node tests/battle/engine/test_*.mjs`（15 个 Node 测试，无需浏览器）；
  - 剧情链路：`node tests/quest_flow.mjs`（30 项：择难度→开局即主线→章节随主线推进→支线解锁→点将出征→立传解耦→任务点错位）；
  - 全链路：`node smoke.mjs`（Playwright，56 项断言 + 验收截图入 `testshots/`）。

## 剧情架构（本版重点重构）

原「17 章 × 每天 4 时段 × 行动点」的时间线**已废除**，改为任务驱动的自由开放世界：

- **开局即主线**：开卷时先选难度，落地即见右侧任务卡与世界的「令」标记，不必先睡觉推进章节。
- **章节由主线驱动**：`G.ch` 不再靠天数累积，而是由主线完成度推导（`Quests.chapterNow()`）。于是"打完这一节，世界就变了一道"——m4 世界马刀协会成立、m6 刀禁期起、m9 收卷进终章。
- **时段与行动点退化为风味**：时段只影响氛围与 NPC 流动（每天随机轮换），事件不再按时段门控，读书/听课/采访/打听不再消耗行动点。HUD 上原来的 ⚡ 行动点位置现在显示**主线进度 n/9**。
- **立传降级为可选支线**：原「未胜传主不可立传」的成传战门禁已撤下，撰史与主线彻底解耦，随时可写。

## 设计约定

- **零依赖**：原生 JS + Canvas 2D + WebAudio 程序合成，无任何外部资源与网络请求。
- **数据驱动**：机制与内容分离；加主线/支线改 `js/quests.js`，加人物改 `data/people.js` + `battle/data.js`，加名场面改 `data/events.js`。
- **引擎不动世界**：战斗引擎通过 `window.SJI_UI` 钩子与覆盖层通信，通过 `SJI_BATTLE_HOOKS` 与世界结算，两侧可独立测试。
- **⚠️ `const` 顶层声明不挂 `window`**：跨脚本访问 `World/Main/Blades/Quests/UI/Engine/DIFFS/PEOPLE_BY_ID` 等，一律用裸名 + `typeof X !== 'undefined'` 判活，**不要写 `window.X`**（本项目共有 5 处此类静默失效，见技术报告 §4）。

## 存档

世界进度存于 `localStorage['shiji_cqb_v1']`（自动 + base64 导出/导入）；战斗侧偏好与断点存于 `shiji_madao_v1`。设置面板可导出/导入/焚稿重开。老档会自动迁移：主线九节从头接起，此前的胜场、刀谱与进度皆保留。
